====================================
ニュースアプリ セットアップ手順
====================================

【所要時間】 約10〜15分
【必要なもの】 Googleアカウント

このアプリは2つのサービスを組み合わせて動きます。
 ・Google Apps Script(GAS) … Googleニュース検索・投資信託情報の取得プロキシ
 ・GitHub Pages          … スマホで開くアプリ本体の公開場所
すべて無料の範囲で使えます。

------------------------------------
STEP 1: Google Apps Scriptプロジェクトを作成
------------------------------------
1. https://script.google.com にアクセスしてログイン
2. 「新しいプロジェクト」を作成
3. エディタに表示されているサンプルコードを全て削除し、
   このフォルダ内の「ニュース_GAS.js」の中身を全てコピー＆ペースト
4. 上部の「保存」（フロッピーアイコン）をクリック

------------------------------------
STEP 2: 投資信託ファンドコードを確認（任意）
------------------------------------
スクリプト冒頭の FUNDS 配列には、以下2つの投資信託が
初期値として設定済みです（2026年時点で動作確認済み）。
  ・eMAXIS Slim米国株式(S&P500)         code: 03311187
  ・eMAXIS Slim全世界株式(オール・カントリー) code: 0331418A

別のファンドに変更したい場合は、finance.yahoo.co.jp で
ファンド名を検索し、投資信託ページを開いた際のURL
（例: https://finance.yahoo.co.jp/quote/XXXXXXXX の末尾部分）
をコピーして code を書き換えてください。
そのままで問題なければ、このSTEPは飛ばしてOKです。

------------------------------------
STEP 3: デプロイ
------------------------------------
1. 右上の「デプロイ」→「新しいデプロイ」
2. 種類の選択で歯車アイコン →「ウェブアプリ」を選択
3. 「次のユーザーとして実行」: 自分
   「アクセスできるユーザー」: 全員
4. 「デプロイ」をクリックし、承認画面が出たら自分のアカウントで許可
5. 発行された「ウェブアプリのURL」をコピーしてメモしておく
   （このURLを後でアプリの設定画面に貼り付けます）

------------------------------------
STEP 4: GitHubリポジトリを作成してアプリを公開
------------------------------------
1. このフォルダ（ニュースアプリ）の中身
   （index.html / manifest.json / sw.js / icon-192.png / icon-512.png）
   をGitHubの新規リポジトリにpush
   ※ ニュース_GAS.js と setup_guide.txt はGAS用の資料なので、
      Pagesの公開対象に含める必要はありません（含めても問題ありません）
2. リポジトリの Settings → Pages で
   公開ブランチ（例: main）を選択して保存
3. 発行されたURL（https://ユーザー名.github.io/リポジトリ名/）を確認

------------------------------------
STEP 5: アプリでGAS URLを設定
------------------------------------
1. STEP4で発行されたURLをスマホやPCのブラウザで開く
2. 右上の ⚙️（設定）をタップ
3. 「GAS Web App URL」欄にSTEP3でコピーしたURLを貼り付け
4. 「保存して再読み込み」をタップ

------------------------------------
STEP 6: 動作確認
------------------------------------
1. 🔄（更新）ボタンをタップし、6つのセクション
   （芸能／経済／鳥取／RIZIN／テスラ／投資信託）が
   表示されることを確認
2. RIZIN・鳥取のニュースは話題が少ない日には
   「現在この分野のニュースが見つかりません」と表示されることがあり、
   これは正常な動作です
3. 投資信託セクションで基準価格・前日比の数値が表示されることを確認
   （取得に失敗した場合は「⚠️ 前回値を表示中」と表示され、
   前回取得できた値がそのまま表示されます）

------------------------------------
使い方のポイント
------------------------------------
・上に行くほど重要度が高いカテゴリを配置しています
・一度取得したデータは端末内に保存されるため、次回起動時は
  まず前回のデータが即座に表示され、裏側で最新データに更新されます
・通信できない状況でも、前回表示していた内容はそのまま見られます
・ホーム画面に追加するとアプリのように起動できます
  （ブラウザの「共有」→「ホーム画面に追加」）
・アイコンは仮のものです。差し替えたい場合は icon-192.png /
  icon-512.png を同名のまま好きな画像に置き換えてください
